# Developer Logos Directory

## Instructions for Adding Developer Logos

Place all real estate developer logos in this folder. The logos should be:

### Image Specifications:
- **Format**: PNG (with transparent background preferred) or JPG
- **Dimensions**: Recommended 400x200px or similar aspect ratio
- **File Size**: Keep under 100KB each for optimal loading
- **Background**: Transparent PNG works best for professional look

### How to Add Logos:

1. **Download logos** from official developer websites
2. **Optimize images** using tools like:
   - TinyPNG (https://tinypng.com/)
   - Squoosh (https://squoosh.app/)
3. **Rename files** to match the names above
4. **Place files** in this directory (`public/logos/`)

### Where to Find Logos:

- **Google Search**: "[Developer Name] logo png"
- **Official Websites**: Look for media/press kits
- **Clearbit**: https://clearbit.com/logo (for some companies)
- **Brandfetch**: https://brandfetch.com/

### Notes:

- If a logo fails to load, the component automatically displays the developer name as fallback text
- Logos are displayed in a responsive grid (2 columns on mobile, 3 on tablet, 5 on desktop)
- Each logo card has hover effects for better user interaction
